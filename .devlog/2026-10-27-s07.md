# 2026-10-27 / s07 — Roll back per-frame selection work and bound zoom-out compositing

Outcome: O6 · State: active
Source: this change · Environment: Linux x64, Node 25.8.0, headless Chromium at 1500×900 DPR 1 and 2

## Result

The user reported choppy zoom and movement in bursts after s06. Reverted s06's
selection overlay and initial/pan scheduling change. Selection is again part of
the cached drawing tiles, so the s06 selection-latency improvement no longer
applies. The cold-open sidecar optimization remains.

Found another concrete source of freezes in the zoom renderer: both `gaps()` and
`paintLayer(..., 0)` enumerated every visible position in the old raster grid.
Zooming out could expose 1,038,236,117 positions while only a few cached tiles
existed. Now gap counting subtracts visible cached tiles from the arithmetic grid
area, and painting during motion iterates only cached tiles. Work stays bounded
by cache size throughout the gesture.

Continuous 72-notch zoom-out tests on the two large drawings now deliver about
16.8 ms p95 frames, without rebuilding tiles mid-gesture, including 1,024 selected
entities. This is synthetic Chromium evidence, not desktop-user acceptance.
The larger drawing still fails the original 460 ms post-zoom sharp-redraw deadline;
that failure is retained, not relaxed. O6 remains active.

## Changes and decisions

- `viewer/canvas.ts`: rolled back s06 renderer edits, then bounded gap counting and
  zero-budget painting by cached tile count. Preserve k=1 pixel rounding, label
  counts, selection rendering and settled redraw behavior.
- `scripts/viewer-check.js`: restored exactly to the pre-s06 file, including its
  original 460/600 ms wheel completion waits. Passing eventual completion after
  relaxing a deadline was inadequate evidence for the reported interaction.
- `scripts/zoom-check.js`: new regression check for empty-grid traversal (aborts
  after 5,000 map probes rather than hanging), active-input delivered frames,
  no tile rebuilding during motion, empty/1,024-entity selection, and completion
  within a fixed one second after the extreme zoom-out stops.
- Measured the s06 overlay with a 9,773-entity selection: 5.2–10.3 ms of drawing
  work on every cached frame versus about 0.1 ms with no selection. This was a
  regression in animation work, even though selection itself was faster.
