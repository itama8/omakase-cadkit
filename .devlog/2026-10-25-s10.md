## Changes and decisions

- `viewer/index.html`, `main.ts`, `style.css`: SVG controls, accessible radio choices,
  ruler preview, explicit Apply, folder scope and save errors. Modal keyboard handling keeps
  drawing shortcuts from running underneath. Save/load lock the controls.
- `src/config.ts`: atomic local `omakase-cadkit.json` writes, preserving all other keys.
  An inherited/legacy profile is copied before changing units; the ancestor stays unchanged.
  Auto deletes the local units key. Folder settings also reach inheriting subfolders.
- `src/server.ts`: properties GET/POST, unit allowlist, bounded JSON request and same-origin
  write guard. The context cache now includes the loaded profile content so every drawing
  sharing that profile sees edits on its next lint. Drawing payloads stay cached.
- The DWG and its header are unchanged. Metric annotations alone are not sufficient to
  distinguish metre geometry from millimetre geometry; the reviewer explicitly selects units.
- The existing local server on port 4280 was restarted from compiled `dist/server.js`.
  No private drawing or profile was edited. Only a disposable synthetic copy was configured.
