## Changes and decisions

- `viewer/canvas.ts`, `viewer/stroke-pool.ts`, `viewer/stroke-worker.ts`: compile
  large high-DPI stroke batches into at most four workers. Each complete batch
  belongs to one worker; composite their consecutive partitions in source order.
  Preserve the original paths, line widths, colours, dash patterns and visibility.
  Text, fills, selection, picking and inspection retain their host paths.
- Resample linked images in one worker, retaining the world transform, fade and
  clip. Repeated immutable ImageBitmap inputs reuse their worker copies; mutable
  canvas sources still copy anew. Explicitly flush deferred Canvas work there before returning a bitmap.
  Missing worker support or errors retain synchronous rendering.
- Start work at the exact target scale after the existing 120 ms input quiet
  interval, while camera easing finishes. Do not build intermediate host raster
  tiles during active input. Finish at the exact requested scale and snap only
  numerically identical grid origins, avoiding a spurious row/column of tiles.
- Retain one prepared worker scene through temporary drawing replacements.
  Compare an immutable coordinate/style snapshot before reusing it; in-place edits,
  origin changes, dashes, extents and theme changes invalidate it. Worker jobs are
  bounded, stale scene results are discarded, and disposal resolves pending jobs.
- Share one completed stroke bitmap across the viewport's raster tiles. Prepare
  ready tiles in short yielding batches, and release temporary frames when the
  visible tiles are complete. A version that created a bitmap per tile passed the
  original suite but missed a later repeat at 563 ms; this was not accepted.
- Reject a pixel-region worker experiment: it changed ordinary stroke pixels even
  with gutters. Preserve complete stroke batches. Later speculative preparation,
  geometry-result adoption and image-only job experiments did not reliably pass
  the original deadline and were removed. The retained source uses the existing
  120 ms input quiet interval.
- `scripts/shot.mjs --dpr <ratio>` makes display-scale reproduction explicit.
  New worker pixel/lifecycle and repeat-redraw checks keep the existing deadlines.
  `scripts/bundle.mjs` also builds the worker asset so a download cannot omit it.
  No payload, schema, converter or updater behavior changed. A complete new download
  and installer were not built or released.

CPU OffscreenCanvas and the host canvas differ at image clip antialiasing edges.
The rotated/faded image contract compares the visible tile core, excluding the
three-CSS-pixel raster gutter. It found 334 differing pixels within two device
pixels of the specified clip, maximum channel delta 70. All image interior pixels
match within 2/255; the stroke-only case matches within 1/255. The test permits
edge AA differences only in that explicit band. This is not pixel-identical
rendering. A full D4 comparison before the final bitmap-sharing cleanup likewise
showed small AA drift (4,487 of 2,721,600 pixels over delta 2; maximum 55).
