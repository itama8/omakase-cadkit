# 2026-10-27 / s05 — Offer and install published updates

Outcome: O11 · State: verifying
Source: this change · Environment: Linux x64, Node 25.8.0, headless Chromium

## Result

Downloaded copies check GitHub on opening the viewer and hourly thereafter. Installed
Windows copies offer **Install and restart**; other downloads link to the release.
The installer download must match GitHub's published SHA-256 and size. Installation
requires a click from the local viewer. Dismissal hides one version only.

This is implemented and checked locally, not released. The alpha.2 tag and its
existing downloads do not contain this updater. Users must manually install the
first release containing it. Native Windows replacement and the browser's reload
across a real version change remain unproven.

## Changes and decisions

- `src/update.ts`: semantic version ordering, draft exclusion, prerelease updates
  for prerelease copies (stable copies stay on stable releases), exact platform
  asset selection, isolated temporary downloads, streaming hash/size validation,
  cleanup on transfer failure and detached installer launch with failure reporting.
  Uses the digest in GitHub's [release asset API](https://docs.github.com/en/rest/releases/assets).
  Missing/invalid hashes fall back to the release link.
- `src/server.ts`: version health field, one shared update lookup cached for an hour,
  same-origin/host checks and duplicate-install protection. Source checkouts and
  `OMAKASE_CADKIT_UPDATE_CHECK=0` disable update checks. Checks send no drawings.
- Viewer: update banner, download/install action, error and retry handling,
  version-specific dismissal, polling for a changed server version before reloading.
- Installer: `/RELAUNCH=1` starts the viewer without opening a second browser tab.
  Preserve the installation folder and viewer port through replacement and restart.
- CI now runs `scripts/check-update-install.mjs` after installing the Windows bundle.
  It replaces a running installation with the same build, verifies a new server PID
  and lints a drawing. This rehearsal is separate from a true version-to-version update.
- README explains the first manual upgrade, checks and opt-out. No version bump,
  tag, publication, npm publishing, or replacement of existing release assets.
