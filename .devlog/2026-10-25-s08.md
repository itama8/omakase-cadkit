# 2026-10-25 / s08 — Viewer performance baseline and review direction

Outcome: O6, O7 · State: queued
Source: this change (background image toggle, header title, per-file view settings, resizable panels, two type sizes) · Environment: Linux x64, headless Chromium with `--disable-gpu`

## Result

A baseline for viewer speed on a heavy drawing, and a narrow direction (view, inspect, review;
no editing) drawn from a read of the mlightcad cad-viewer source. Nothing is faster yet.

## Changes and decisions

- Pan (cached raster tiles) and pick (hit grid) are already cheap. Zoom is the bottleneck: the
  tile cache key in [`viewer/canvas.ts`](../viewer/canvas.ts) includes the exact scale, so each zoom
  frame repaints every visible path and label, and smooth zoom repaints several times per wheel
  notch. The same key includes the selection, so a click also repaints every tile.
- Taken from cad-viewer: keep geometry fixed and make view changes cheap; draw selection, hover,
  findings and compare roles as overlays that never invalidate geometry; repaint only when dirty.
  Their WebGL batching is the long-term option. Try it only if scaled-tile zoom misses the O6
  target, because text rendering is the expensive part to port.
- Background image toggle: raster visibility used to follow only its layer. On the benchmark
  drawing the aerial image shares layer `0` with about 11.8k primitives, including survey
  polylines, so hiding the layer hid that linework. A "Background image" toolbar button and the
  `B` key now hide or show every raster image regardless of layer
  ([`viewer/canvas.ts`](../viewer/canvas.ts) `showImages`, [`viewer/main.ts`](../viewer/main.ts)).
  The same switch is pinned as the first row of the layers panel, with an image icon in place of
  a layer swatch, the image count, and a rule below it. It is hidden while the layer filter has
  text. Layer All, None and Alt-click isolate leave it alone, since it is not a layer. The button
  and row appear only when the drawing has images. It is named for what the reviewer sees,
  not the CAD term "underlay".
- Alt-click on the isolated layer shows every layer again.
- The header shows the drawing title (file name without extension, full path on hover) with a
  folder button instead of an editable path. The button opens Files and browses the drawing's
  folder. Browse now sits above Recent, and typed paths moved to a field at the top of Browse:
  a `.dwg`/`.dxf` path opens the file, anything else is browsed, and `~` still works.
- Per-file view settings: hidden layers (by name) and the background image are saved in
  `localStorage` (`omakase-cadkit-views`, most recent 50 files) and restored on reopen.
  `/api/drawing` now sends `x-omakase-cadkit-file-version` (`size-mtimeMs`, a header, not a
  payload schema change); if it differs from the saved entry, the entry is dropped and the file
  opens with its own layer state and the image on. Settings live in the browser profile, so
  another browser or machine starts fresh.
- Resizable panels: drag the inner edge of the left or right panel, or the divider between Browse
  and Recent; double-click resets; arrow keys step 16 px (Shift 64). Sizes are a global layout
  preference in `localStorage` (`omakase-cadkit-layout`), capped by CSS at 45/50 vw so the drawing
  keeps room. Handles are hidden at the narrow overlay breakpoint. Findings, Inspect and Sheet
  are single lists, so they have no inner divider.
- Resizing no longer flushes the raster-tile cache: the cache key dropped canvas width and height
  (tiles are anchored to drawing space), and tiles composite at whole pixels so a half-pixel
  centre does not blur text. Opening a drawing now also browses its folder.
- Type scale: the stylesheet had 16 font sizes (6.5–22 px). UI text now uses two tokens in
  [`viewer/style.css`](../viewer/style.css): `--fs-body` 13 px for content you read (layer, file
  and search names, finding messages, inspect values, title, help) and `--fs-small` 11 px for
  labels, counts, metadata and compact controls. Uppercase labels lost some tracking to suit the
  larger small size. Exceptions: the empty-state heading (22 px) and the label inside the
  empty-state SVG art. File names and search hits moved from mono to sans so long names fit;
  mono stays for numbers, handles, paths and sizes. Section labels no longer wrap.
- Out of scope for now: their command line, drawing snaps, grips, plugins and editing.
